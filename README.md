# ТОН

Браузерный тренажёр тональных отношений для художников. Пользователь загружает изображение, отмечает 4–6 крупных пятен от светлого к тёмному и проверяет порядок в чёрно-белом режиме.

## Локальный запуск

Откройте `dist/index.html` в браузере или запустите любой статический HTTP-сервер из папки `dist`.

## Публикация на GitHub Pages

Готовая версия публикуется из ветки `gh-pages`. Исходники приложения находятся в папке `dist` ветки `main`.

Приложение работает полностью в браузере: изображения никуда не отправляются.
